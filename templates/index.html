How it works

Scrape
Fetches 18 public lists in parallel (ProxyScrape, GitHub mirrors, Geonode, JetKai…). Deduplicates and shuffles. No API key.
Validate
80 concurrent workers hit httpbin.org/ip through each proxy, measure latency, mark valid / dead / timeout.
Export
Copy valid proxies or download as TXT/JSON/CSV for your bot, scraper, or browser. Proxies stay in-memory until you clear.
Free proxies are volatile — expect 5–15% valid at any time. Re-scrape hourly. For anonymity, validate via https://api.ipify.org?format=json and check returned IP.
